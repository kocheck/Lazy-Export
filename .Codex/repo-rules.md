# Repo Rules — Lazy Export (Figma Plugin)

> Consulted by the `tidy-repo` skill before every commit/PR audit.

## Allowed at root

- README.md
- LICENSE
- ARCHITECTURE.md
- CHANGELOG.md
- CONTRIBUTING.md
- ERROR_REPORTING.md
- IMPLEMENTATION_SUMMARY.md
- PRIVACY.md
- TESTING.md
- build-plugin.js
- eslint.config.mjs
- package.json
- package-lock.json
- tsconfig.json
- vite.config.ts

(dotfiles — `.gitignore`, `.cursorrules`, `.claude/`, `.Codex/`, etc. — always allowed)

## Directory purposes

- `src/` — all TypeScript/TSX source (plugin, UI, shared, tests)
- `dist/` — build output (committed; regenerated by `npm run build`)
- `docs/` — design docs, architecture notes, references
- `plans/` — handoff plans for agent executors (NNN-*.md)
- `public/` — static assets (manifest.json, icons)
- `assets/` — source design assets
- `.Codex/` — repo conventions and agent rules (committed)
- `.context/` — agent scratch (gitignored, never commit)
- `node_modules/` — dependencies (gitignored)

## Routing rules

- design docs / specs → `docs/`
- executor handoff plans → `plans/`
- one-off scripts → root (if build-related) or `scripts/`
- scratch notes / brain dumps → `.context/` (do NOT commit)

## Forbidden patterns

- `NOTES.md`
- `TODO.md`
- `scratch.md`
- `untitled*`
- `*.tmp`, `*.bak`, `*.swp`
- `.DS_Store`
- `Thumbs.db`

## Exceptions

- `IMPLEMENTATION_SUMMARY.md` — historical v2.0 milestone record; kept at root intentionally

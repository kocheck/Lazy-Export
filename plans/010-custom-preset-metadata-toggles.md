**Goal:** Make the two per-preset flags `generateMetadata` and `directoryStructure` real,
end-to-end:
1. **UI** — `PresetCreator.tsx` hardcodes both flags to `false` when saving (lines 59-60).
   Add a "Generate Metadata" toggle and a "Use Directory Structure" toggle to the form
   (reusing the existing `Toggle` component), initialize them from `existingPreset` when
   editing, and save the real values.
2. **Plugin** — `applyExportSettings` (`src/plugin/main.ts`) currently ignores those flags. It
   emits the iOS `Contents.json` message whenever `advancedMode && platform === 'iOS'`
   (lines 204-211) and applies directory-path suffixes whenever `advancedMode && platform`
   (lines 158-167). Without a plugin change the new UI toggles are **dead data**. Widen the
   function so the precedence is explicit:
   - **directory paths** require `advancedMode && preset.directoryStructure`
   - **iOS `Contents.json`** requires `advancedMode && preset.generateMetadata`

**Why this matters:** Right now a user can set a preset's intent, but the plugin reads only the
global Advanced-Mode toggle, so the per-preset flags do nothing. This plan connects the saved
flags to the actual export behavior.

BLOCKER (the plugin change is required, not optional — without it the flags are dead).

```ts
        typeof call[0].metadata.iosContentsJson === 'string'
    );
  }

  const iosSettings = [{ format: 'PNG' as const, suffix: '@1x' }];

  it('advanced ON + generateMetadata OFF ⇒ no Contents.json message', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    // advancedMode=true, platform=iOS, generateMetadata=false, directoryStructure=true
    applyExportSettings(figmaMock.currentPage.selection, iosSettings, 'asset', true, 'iOS', false, true);

    expect(contentsJsonPosted()).toBe(false);
  });

  it('advanced ON + generateMetadata ON (iOS) ⇒ Contents.json message posted', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    applyExportSettings(figmaMock.currentPage.selection, iosSettings, 'asset', true, 'iOS', true, true);

    expect(contentsJsonPosted()).toBe(true);
  });

  it('advanced ON + directoryStructure OFF ⇒ plain suffix, no folder path', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    // directoryStructure=false ⇒ falls through to the custom-name branch: `/asset@1x`
    applyExportSettings(figmaMock.currentPage.selection, iosSettings, 'asset', true, 'iOS', false, false);

    const applied = node.exportSettings[0];
    expect(applied.suffix).toBe('/asset@1x');
    expect(applied.suffix).not.toContain('.imageset');
  });

  it('advanced ON + directoryStructure ON (iOS) ⇒ .imageset folder path', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    applyExportSettings(figmaMock.currentPage.selection, iosSettings, 'asset', true, 'iOS', false, true);

    const applied = node.exportSettings[0];
    expect(applied.suffix).toBe('/asset.imageset/asset@1x');
  });

  it('both ON (iOS) ⇒ Contents.json message AND .imageset path', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    applyExportSettings(figmaMock.currentPage.selection, iosSettings, 'asset', true, 'iOS', true, true);

    expect(contentsJsonPosted()).toBe(true);
    expect(node.exportSettings[0].suffix).toBe('/asset.imageset/asset@1x');
  });

  it('advanced OFF ⇒ flags ignored, no Contents.json (default-preset behavior unchanged)', () => {
    const node = createMockNode();
    figmaMock.currentPage.selection = [node];

    // Mirrors the applyIOS command call site: advancedMode=false, flags default false.
    applyExportSettings(figmaMock.currentPage.selection, iosSettings, undefined, false, 'iOS');

    expect(contentsJsonPosted()).toBe(false);
    // No customName and advanced off ⇒ suffix stays the raw setting suffix.
    expect(node.exportSettings[0].suffix).toBe('@1x');
  });
});
```
> **Expected-suffix rationale** (matches the precedence in Task 3 against the current
> directory-path logic): with `directoryStructure` ON and `platform === 'iOS'`, the iOS branch
> builds `/${assetName}.imageset/${assetName}${scale}` where `scale = setting.suffix || '@1x'` →
> `/asset.imageset/asset@1x`. With `directoryStructure` OFF but a `customName` and a `setting.suffix`,
> the `else if (customName && setting.suffix)` branch builds `/${assetName}${setting.suffix}` →
> `/asset@1x`. With `advancedMode` OFF and no `customName`, neither branch runs, so `suffix`
> stays the raw `'@1x'`.

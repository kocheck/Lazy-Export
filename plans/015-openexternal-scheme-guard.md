# 015 — Validate the URL scheme before `figma.openExternal`

> **Planned at:** `df82c72`, 2026-06-14
> **For the executor:** This is a self-contained handoff plan. You have zero prior context.
> Implement task-by-task, in order. Steps use checkbox (`- [ ]`) syntax — check them as you go.

**Goal:** Make the `open-external-url` message handler refuse anything that is not an `http(s)` URL
before passing it to `figma.openExternal`, and cover the case with tests.

**Why this matters:** `handleUIMessage`'s `open-external-url` case passes `msg.url` straight to
`figma.openExternal` with no validation (`src/plugin/core.ts:371-373`). Every current sender uses the
constant `BUG_REPORT_ISSUE_URL` (an `https://github.com/...` link), so it is safe **today** — but the
plugin handler is the trust boundary and should not assume that. A cheap `http(s)`-only guard means a
future or refactored sender can never hand a `javascript:` / `data:` / `file:` URL to the host. The
case is also currently uncovered by tests (the coverage report marks it as not executed).

**Findings addressed:** F5 (audit at `df82c72`).

**Effort:** S · **Depends on:** none beyond a green baseline. This is a defensive hardening with no
behavior change for the existing (constant, `https`) senders.

**In scope (only these files may change):**
- `src/plugin/core.ts` (the `open-external-url` case)
- `src/plugin/core.test.ts` (add two cases)
- `dist/code.js` (regenerated by `npm run build` — commit it)

**Out of scope:** Do **not** change the senders `src/ui/components/Toast.tsx` or
`src/ui/components/ErrorBoundary.tsx` — they already pass a safe constant. Do **not** change the
`UIMessage` union or `BUG_REPORT_ISSUE_URL`. No UI source changes (so `dist/index.html` must stay
unchanged).

## Tasks

### Task 1: Guard the scheme

**File:** `src/plugin/core.ts`

- [ ] Replace the `open-external-url` case body so it only opens `http:`/`https:` URLs; otherwise
  post a user-facing error and stop. Target shape:
  ```ts
  case 'open-external-url': {
    let allowed = false;
    try {
      const scheme = new URL(msg.url).protocol;
      allowed = scheme === 'http:' || scheme === 'https:';
    } catch {
      allowed = false;
    }
    if (allowed) {
      figma.openExternal(msg.url);
    } else {
      const rejection: PluginMessage = {
        type: 'error',
        message: 'Refused to open a non-web URL.',
      };
      figma.ui.postMessage(rejection);
    }
    break;
  }
  ```
  (If `URL` is not available in the plugin sandbox's typings, fall back to a
  `/^https?:\/\//i.test(msg.url)` check — but prefer `URL`.)
- [ ] `npx tsc --noEmit` → exit 0.
- [ ] Commit: `"Guard openExternal to http(s) URLs only"`
